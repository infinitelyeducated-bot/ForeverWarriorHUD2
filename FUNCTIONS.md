# ForeverWarriorHUD2 function map

Generated by make2.cjs from ForeverWarriorHUD. Line numbers are for ForeverWarriorHUD2.lua.

## Where an option lives

Every setting follows the same five steps. Adding an option means touching each once.

| Step | HUD / element / spell options | Text options |
|---|---|---|
| 1. Default value | `DEFAULTS` (top of file) | `DEFAULTS.text` |
| 2. Validate on load and on profile load | `ApplyConfig`, `ClampSwing`, boot handler | `TXT.Clamp` |
| 3. Saved in profiles | name listed in `CONFIG_KEYS` | already covered by `"text"` |
| 4. Widget | `MakeCheck` / `MakeSlider` / `MakeButton`, then `Row(flow, ...)` | the "Text tab" block |
| 5. Show the saved value | `FRHW2_RefreshPanel`, `RefreshConfig` | `TXT.Refresh` |
| 6. Make it take effect | `ApplyElement`, `ApplySpell`, `ApplySkin`, `PaintSwing`, `LayoutSwing` | `TXT.Apply`, `TXT.Paint`, formatters |

Rules that keep it fast and safe on this client:

- Work that depends only on settings goes in an Apply function, never in an update function. Update functions (`UpdateEnergy`, `UpdateRegen`, `UpdateSwingBar`, `UpdateSpellIcon`) run every frame or ten times a second.
- A value from the game may be secret. Hand it to a widget; only do arithmetic on it after `IsReadable`.
- The main chunk is close to Lua's 200-local limit. New state goes in a table (`TXT`, `swingUI`, `cdUI`), not a new top-level local.
- Sliders write to the saved settings only when `suppress` is false, so refreshing the window never changes them.

## Text engine (new in the 2 build)

Settings: `ForeverWarriorHUD2_DB.text` = font, outline, shadow, useSkinColor, r, g, b, and one block per text (`energy`, `regen`, `swing`, `timer`) with size, anchor, x, y and, where it applies, format and decimals.

Typeface precedence, most specific first: the tracked ability's own (`ForeverWarriorHUD2_DB.spells[key].font` / `.fontSize`, set on the Config tab in that ability's block), then its group's (`text.<target>.font`, Text tab), then the global `text.font`. nil at any level means "inherit".

- The typeface list is built once at login by `TXT.LoadSharedFonts`: the built-in rows of `TXT.FONTS`, every font file the client uses (`GetFonts()`), and every LibSharedMedia font. To ship another font, add a row to `TXT.FONTS`.
- Every font button opens the one shared list, `TXT.OpenPicker(owner, current, allowInherit, onPick)`. A new font button anywhere is one `MakeButton` calling it, plus a `TXT.Label` line in `TXT.Refresh`.
- New per-ability option: validate it in `TXT.ClampItem`, add the widget to the "Config tab font row" splice in make2.cjs, refresh it in the Config loop of `TXT.Refresh`, use it in `TXT.Apply`.
- New outline style or anchor: add a row to `TXT.OUTLINES` / `TXT.ANCHORS`.
- New number format: add a row to that target's `formats` in `TXT.TARGETS`, then handle its key in the formatter (`TXT.Energy`, `TXT.Regen`, `TXT.Timer`).
- New text on the HUD: create the font string, add a row to `TXT.TARGETS`, a default block in `DEFAULTS.text`, and one `TXT.Place` line in `TXT.Apply` (plus `TXT.Paint`). The Text tab builds its controls from `TXT.TARGETS`.

Chat and macros: `/fw2 text` opens the tab, `FRHW2_SetFont("friz")`, `FRHW2_ApplyText()`, `FRHW2_TEXT` (the engine table).

## Unit frames (new in the 2 build)

Settings: `ForeverWarriorHUD2_DB.frames` = one block each for `player`, `target`, `targettarget` (enabled, hideBlizzard, x, y, w, h, powerH, scale, alpha, color, name, health, powerText, font, fontSize). Source: frames2_section.lua.

- A frame is built by `UF.Create` the first time it is switched on; off means no frame and no events.
- They are secure unit buttons, so `UF.Apply` (place, size, show, hide, hide the game's frame) waits for combat to end. `UF.Health`, `UF.Power`, `UF.Tint`, `UF.Fonts`, `UF.Paint` are free to run in combat.
- New unit (focus, pet): add a row to `UF.UNITS` and a default block to `DEFAULTS.frames`. The Frames tab builds itself from `UF.UNITS`.
- New per-frame option: ONE row in `UF.OPTS` (key, type, label, default, range or list). The default, the validation, the widget and the refresh all come from that row (`TXT.ClampOptions`, `TXT.BuildOptions`, `TXT.ShowOptions`). Then use `db.frames[key].<k>` in `UF.Apply` / `UF.Layout` / `UF.Fonts` or the update that needs it (`UF.Health`, `UF.Power`, `UF.Tint`, `UF.Name`, `UF.Portrait`, `UF.Icons`, `UF.Threat`, `UF.Fade`).
- The Frames tab edits one unit at a time (`UF.sel`); `only = {...}` on a row greys it out for the other units.
- Extras (frames3_section.lua): cast bar `UF.Cast`, buffs / debuffs `UF.FillAuras`, aura bars `UF.AuraBars`, incoming heals `UF.Heal`, custom texts `UF.Custom`, combo points `UF.Combo`, status icons `UF.Status`; all placed by `UF.LayoutMore`, routed by `UF.ROUTE`. Cutaway lives in `UF.Health`, the info panel in `UF.Layout`. Colour options are schema rows of type `color` and open `TXT.OpenPalette`. `FRHW2_ApplyNow()` (the Apply button, `/fw2 apply`) pushes everything again. A font pack addon fills the global `ForeverFonts` list.

## Map (new in the 2 build)

Settings: `ForeverWarriorHUD2_DB.map`. Source: map2_section.lua. New option: one row in `MP.OPTS`, then use `db.map.<k>` in `MP.Apply` (minimap) or `MP.World` / `MP.WorldShow` (world map). Every change to a game frame is recorded in `MP.state` and undone when the option is unticked; hidden pieces go through `TXT.Stash`. `/fw2 map` opens the tab; `FRHW2_ApplyMap()`, `FRHW2_MAP`.

Unit frames, continued:

- New health-text format or colour mode: a row in `UF.HEALTH` / `UF.COLORS` (formats are rendered by `TXT.Value`).

Chat and macros: `/fw2 frames` opens the tab, `FRHW2_ApplyFrames()`, `FRHW2_FRAMES` (the engine table).
